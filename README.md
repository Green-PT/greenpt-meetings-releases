# GreenPT Meetings for Mac: releases

Signed, notarized builds of GreenPT Meetings for Mac, and the Sparkle feeds the
installed app checks for updates.

- `appcast-production.xml`: GreenPT Meetings
- `appcast-develop.xml`: GreenPT Meetings (Develop)

Each build is attached to a GitHub Release here. Everything is published by the
release workflow in the app repository. Do not edit by hand.
